# TalentPulse - LinkedIn Applicants \& CV Downloader

TalentPulse is a browser extension designed for recruiters and HR professionals to export LinkedIn job applicant data to CSV/JSON and download candidate PDFs locally.

## Features

* Export candidate lists directly to CSV or JSON formats.
* Batch download applicant CVs/Resumes in PDF.
* 100% local processing in the browser for maximum privacy and security.
